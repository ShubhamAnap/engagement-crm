1. PRODUCT OVERVIEW
================================================================================

EnerTech Engage is an enterprise AI customer engagement platform for EnerTech
UPS. It combines omnichannel inbox, CRM (leads/customers), product catalog,
knowledge base (RAG), AI agents, automation workflows, broadcasting
(WhatsApp + Gmail), analytics, and reports.

Goal: Convert a UI prototype into a working multi-channel sales & support
platform that can later become multi-tenant SaaS.

Brand rules:
- Product name is always "EnerTech Engage"
- No third-party builder branding, telemetry, or marketing links

Default organization ID (seeded):
  a0000000-0000-4000-8000-000000000001

Roles (profiles): Admin, Manager, Agent, Sales

4. DEPLOYMENT (RENDER)
================================================================================

Blueprint: render.yaml (Web Service + 5-minute automations cron)

Manual Web Service tips:
- Runtime: Node (not Bun)
- Build: bash scripts/render-build.sh  OR  npm install --include=dev && npm run build
- Start: npm run start:check  OR  npm start
- Set VITE_APP_URL to the public HTTPS URL and redeploy after first deploy
- Free tier sleeps — prefer Starter for WhatsApp webhooks

Cron job:
  POST {VITE_APP_URL}/api/cron/automations
  Header: Authorization: Bearer {CRON_SECRET}
  Interval: every 5 minutes (*/5 * * * *)

Cron runs:
- Due automation follow-ups
- Wait-step resumes
- IndiaMART / TradeIndia historical backfill ticks
- IndiaMART / TradeIndia auto lead sync (if toggle ON)

9. CHANNELS (DETAILED)
================================================================================

9.1 Website chat
- In-app ChatWidget + public /embed + public/widget.js
- Visitor capture: name, email, phone, company, location
- Creates/links customer + lead; merges same-contact threads
- OpenAI replies via server (RAG + catalogue links)
- Human takeover pauses AI (conversation status = human)
- Attachments: image/PDF

9.2 WhatsApp (Meta Cloud API)
- Configure Phone Number ID, Access Token, Verify Token, WABA ID
- Webhook: /api/webhooks/whatsapp
- Inbox agent replies send via Graph API
- 24-hour customer care window (wa_last_customer_at)
  - Free-form text/attach only while window open
  - Closed → use approved Template from Inbox or Broadcasting
- Inbox Template picker (APPROVED templates + variables)
- Product Recommend (Path B): image + caption from Products catalog
- Templates/campaigns also on /broadcasting

9.3 Email
- SMTP outbound + inbound webhook /api/webhooks/email
- Gmail OAuth (n8n-style) preferred for marketing send
  - Channels → Gmail: Client ID/Secret, Connect with Google
  - Callback: /api/oauth/gmail/callback
  - Send Email dialog (Text/HTML)
  - Broadcasting → Gmail campaigns

9.4 Facebook / Instagram
- Meta Page Messaging
- Webhooks: /api/webhooks/facebook, /api/webhooks/instagram
- Inbox outbound replies

9.5 IndiaMART
- CRM key from seller.indiamart.com/leadmanager/crmapi
- Sync leads now (latest window; max 7 days; 1 pull / 5 min)
- Historical backfill (≤365 days, 7-day chunks, 5-min gaps)
- Push webhook /api/webhooks/indiamart
- Creates Leads (source indiamart) + Inbox threads
- AUTO LEAD SYNC toggle on Channels:
    OFF = manual Sync only
    ON  = cron schedule presets:
          - Every hour
          - Every 6 hours
          - Once a day at IST time (6 AM / 9 AM / 12 PM / 3 PM / 6 PM / 9 PM)
- Marketplace Inbox replies default via WhatsApp phone when available

9.6 TradeIndia
- My Inquiry API (userid, profile_id, key)
- Sync last 24 hours; historical backfill day-by-day (~1 min gap)
- Dedup by rfi_id; source tradeindia
- Same Auto lead sync toggle + presets as IndiaMART
- Automation trigger: tradeindia_lead

9.7 Brainmine CRM+
- Read-only pull → master leads (source brainmine)
- Configurable base URL / auth / path (ERPNext-style defaults)

23. HOW TO USE — QUICK USER GUIDE
================================================================================

Login
  Open app → /login → Admin/Agent credentials

Enable IndiaMART / TradeIndia auto sync
  Channels → IndiaMART or TradeIndia panel
  → Configure credentials if needed
  → Flip Auto lead sync ON
  → Choose Every hour / Every 6 hours / Once a day (+ IST time)
  → Toggle OFF anytime to use only Sync leads now

Manual sync
  Channels → Sync leads now (respects API cooldowns)

Historical import
  Channels → Historical backfill → From/To → Start (leave cron running)

WhatsApp inbox
  Open WhatsApp thread → reply while green window open
  If closed → Template icon → pick APPROVED template
  Recommend icon → pick product card to send

Products for WhatsApp cards
  Products → Edit → upload WhatsApp card image (+ optional PDF)
  Run migration 019 if image columns missing

Website widget
  Channels → copy embed snippet (widget.js + public key)
  Or open /embed for preview

Broadcasting
  Create/sync WA templates; run campaigns
  Or Gmail channel for email blasts

Automation
  Create workflow → trigger → optional Wait/If-Else → actions → Live
  Cron processes waits and follow-ups
